Stop 01 / 06 · Est. 2004 Ubuntu

“The distro that convinced an entire generation Linux is easy — then quietly pivoted to enterprise cloud and left beginners reading the manual alone.”

2004Founded
CanonicalMaintainer
4.10First release “Warty”

// origin

Founded 2004 by Mark Shuttleworth & Canonical Ltd. Named after Nguni Bantu philosophy — “humanity to others.” Shuttleworth funded it from selling Thawte to VeriSign for $575 million. First release: Ubuntu 4.10 “Warty Warthog,” October 2004.

// evolution

Introduced the controversial Unity desktop in 2011, dropped it in 2017, returned to GNOME. LTS releases every 2 years with 5 years of support.

// user archetype
The enthusiastic newcomer who recommends Ubuntu to everyone — including their grandmother and their refrigerator.
⚠ closed-source asterisks
  • 2012 Amazon Shopping Lens — EFF called it spyware; removed 2016
  • Snap Store backend — proprietary infrastructure
  • ubuntu-report telemetry — opt-out since 18.04
  • FSF does not endorse Ubuntu
// secret truth

Ubuntu is to Linux what training wheels are to cycling — essential at first, slightly embarrassing to still have at age 30.

$ verdict “Perfect entry point. Just don’t tell anyone you’re still using it in three years.”

Origin

Created by Patrick Volkerding, first released July 16, 1993. Based on SLS Linux, published via FTP on funet.fi. “Slackware” was a joke about “slacking off.” One of the most widely used distros of the 1990s.

Design Philosophy

KISS principle taken to its logical extreme. No automatic dependency resolution. No GUI installer. No hand-holding.

One-Man Army · Slackware 15.0

Released February 2022 — after a six-year development cycle. Patrick Volkerding maintains it almost entirely alone.

$ verdict “If you can install Slackware from scratch, you can fix literally anything on any system, ever.”

Slackware is the Linux puritan’s choice — no conveniences, no excuses, and legendary respect for those who persist.

Stop 04 / 06 Linux Mint

Everything Ubuntu promised, minus the corporate rebranding and the inexplicable insistence on Snap.

2006Founded
CinnamonDesktop born 2011
#1DistroWatch most visited

// origin story

Founded 2006 by Clément Lefèbvre as a polished Ubuntu derivative. When Canonical removed GNOME 2 in 2011, Clément forked it and created the Cinnamon desktop — one of the most beloved DEs in Linux.

★ ZERO SNAP TRAUMA

Ships with codecs and apps pre-installed. Philosophical opposition to Canonical's packaging. The easiest path from Windows to Linux.

Cinnamon Desktop

Beginner-friendly, no Wayland drama — just works out of the box.

No Snap Packages

Codecs and apps pre-installed; a principled “no” to Canonical's store.

Windows Migrants Welcome

Familiar workflows, zero first-boot drama.

Mint users are statistically the most likely to actually get work done instead of tweaking dotfiles for six hours.

// origin

Created 2002 by Judd Vinet, inspired by minimalist CRUX Linux. Leadership passed to Aaron Griffin in 2007, then community-led from 2020.

// rolling release model

No “Arch 2.0” — install once, update continuously forever. Packages stay cutting-edge; users stay reading upgrade notes.

“I use Arch btw” originated on Linux forums ~2011, went mainstream on Reddit by 2018. In 2021, archinstall made setup less terrifying. The smugness remains.

// user archetype The person who mentions their OS in unrelated conversations, their dating profile, and their last will and testament.

The Arch Wiki — so thorough that users on other distros consult it daily. The finest documentation in all of computing.

Arch is the Linux enthusiast’s rite of passage — minimalist by design, maximalist by reputation.

// honorable mention · NOT LINUX · HONORARY UNIX FreeBSD

FreeBSD is a complete UNIX-like OS with its own kernel and userland — not a Linux distribution, not a derivative. A separate lineage entirely.

// key_points[1]

Native ZFS support years before Linux caught up. When everyone else was arguing about filesystems, FreeBSD already had the answer.

// key_points[2]

The FreeBSD Handbook makes the Arch Wiki feel like a README. Comprehensive, precise, and maintained with the rigor of the OS itself.

archetype: The ex-Linux user who grew tired of kernel politics — hasn’t reinstalled since 2017.

FreeBSD earns its honorable mention with 30+ years of powering the internet’s most demanding workloads.

Stop 06 / 06 · Grand Finale · ENDGAME NixOS

“You have tried every other distro. You are ready. Welcome to the final boss of Linux.”

/etc/nixos/configuration.nix 
services.nginx.enable = true;
users.users.alice.isNormalUser = true;
environment.systemPackages = [
  pkgs.git
  pkgs.vim
];
# $ nixos-rebuild switch
# atomic update. rollback anytime.

Born from Eelco Dolstra's 2003 PhD at Utrecht University. Packages installed via cryptographic hashes in an immutable store. NixOS 1.0 shipped 2013 — by 2022, “infrastructure as code” made it fashionable.

Fully Declarative

Atomic Rollbacks

Reproducible Builds

Home Manager

Functional Nix Lang

The OS is a value

// WHY_IT_IS_DIFFERENT

→ Not just a package manager — a new philosophy

→ Your config is a Git repo. Dotfiles, shell, editor — all managed.
